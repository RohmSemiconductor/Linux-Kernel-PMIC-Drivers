# ROHM Power Management IC BD73900

The ROHM BD73900 is a Power Management IC which can be controlled using I2C. It includes similar hardware blocks
as the [BD72720](../BD72720/).

## Linux:

The BD72720 Linux driver can be used to control the BD73900, and BD72720 device-tree compatible can be used as a fall-back compatible for the BD73900. The BD72720 device-tree bindings are planned to be modified to document this, this documentation update is planned to be upstreamed during v6.20 development cycle.

Please, see the [BD72720](../BD72720/) for more information regarding the hardware / Linux drivers.
